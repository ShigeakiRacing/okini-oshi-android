Android版 APKをダウンロード
このAndroid版はGoogle Play版ではありません。 APKを直接ダウンロードしてインストールします。

インストール方法

  1. 上の「Android版 APKをダウンロード」をタップします。
  2. ダウンロードしたAPKを開きます。
  3. 初回のみAndroidから確認された場合は、 「この提供元からのアプリを許可」を有効にします。
  4. 「インストール」をタップします。

バージョンアップ時は、同じページから新しいAPKを ダウンロードしてインストールしてください。
